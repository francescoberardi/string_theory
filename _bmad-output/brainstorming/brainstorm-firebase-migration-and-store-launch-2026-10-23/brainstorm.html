Technique 02 · Structured Domain & UX Rethink

SCAMPER Method — Data Model & Experience Transformation

Applying structured SCAMPER lenses to collapse four relational tables into two high-leverage Firestore collections, preserve rich session history, and plant the seeds for Pro analytics.

C · COMBINE
Locked in v1 User

Unify StringJob & RestringEvent Into One Model

Combine StringJob and RestringEvent into a single unified model instead of maintaining two separate entities and tables.

E · ELIMINATE & ADAPT
Locked in v1 Coach

Restringing = Archiving into pastStringJobs

Treat “restringing” as simply archiving the current StringJob into a pastStringJobs array/subcollection on the Racquet with an endedAt timestamp and reason, eliminating RestringEvent completely.

M · MODIFY & PRESERVE
User Decision · v1 User

Keep Dedicated SessionLog Collection for Rich History

Overruled Coach’s idea to eliminate the SessionLog screen in favor of quick-tap chips only: Keep SessionLog as a dedicated entity/collection so players can view their playing session history and later attach metadata like court location, surface, or notes.

S · SUBSTITUTE (ATOMIC SYNC)
Locked in v1 Coach

Atomic Firestore WriteBatch on Session Log

When logging a SessionLog, execute a Firestore WriteBatch so creating the session document and incrementing hoursPlayed on the Racquet’s active StringJob happen atomically in one network call.

P · PUT TO OTHER USE
v1.2+ Could Coach

String Lab Pro Longevity Analytics

Use the unified StringJob lifecycle log to compute personal string longevity analytics (average hours before dead/broken per string brand) as a future Pro monetization feature.

R · REVERSE

E · ELIMINATE (FOR V1)

Skip Local Decay Notifications Until Real FCM Push

Skip local decay notifications in v1; defer notifications until real push notifications (Firebase Cloud Messaging) are implemented in a future release.

SYNERGY 01

Zero-Cost Google Play Web Account Deletion

Combining Google-only Auth + cutting Guest mode + shipping the Flutter Web App on Firebase Hosting with the delete-user-data extension solves Google Play’s mandatory external web account deletion URL requirement for free—users simply sign in with Google on the web app and tap Delete Account.

SYNERGY 02

Express Lane Through Google Play Review

Cutting Health Connect (which triggers high-scrutiny health permission audits) while deferring Ads & IAP to v1.1 (while pre-wiring Remote Config flags and Crashlytics/Analytics in v1.0) eliminates the two biggest Play Console review bottlenecks so v1 ships immediately.

SYNERGY 03

Pro Analytics Engine at Zero Extra v1 Read Cost

Merging StringJob + RestringEvent inside the Racquet document while keeping SessionLog separate via atomic WriteBatch keeps gear bag loads to 1 collection read today while quietly accumulating the exact dataset needed for v1.2 “String Lab Pro” longevity insights.
